# Python ile Hidroelektrik Enerji Üretimi ve Performans Analizi

Bu proje, hidroelektrik enerji üretimini etkileyen debi, ekolojik su bırakımı, türbin debi kapasitesi ve cebri boru hidrolik kayıplarını inceleyen eğitsel bir Python simülasyonudur.

**Önemli veri notu:** Kullanılan tüm debi ve sistem parametreleri örnekleme amacıyla varsayılmıştır. Kavşak Bendi HES veya başka bir santralden alınmış ölçülmüş işletme verileri değildir.

Teknik raporun Türkçe sürümü `Hydropower_Technical_Report_TR.pdf` ve `.docx` dosyalarında, İngilizce sürümü ise `../en/` klasöründedir.

Temel senaryoda yıllık enerji üretimi yaklaşık **102.056 GWh**, yıllık ortalama güç **11.650 MW** olarak hesaplanmıştır.

HydroGenerate ile sayısal karşılaştırma henüz bağımsız olarak doğrulanmamıştır.
